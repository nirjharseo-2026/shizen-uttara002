# Shizen Uttara

Website for Shizen Uttara, a beauty salon & spa in Uttara, Dhaka.

Single static page: open `index.html` in a browser, or host it on GitHub Pages, Netlify or any static host.

## Before going live
Search `TODO` in `index.html` and fill in:
- WhatsApp / phone number (`CONFIG` in the script)
- Exact address and opening hours
- Service prices
- Real photos, Google reviews and social links
